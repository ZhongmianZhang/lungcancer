node01EGFR / ERBB2 / MET / RET / FGFR1 / FGFR2 / FGFR3 / AXL

上游RTK旁路：EGFR/ERBB2/MET/RET/FGFR与RAS-RAF连接

深入机制、标志物解释及研究性干预

EGFR被奥希替尼抑制后，细胞不一定失去所有上游生长信号。MET、ERBB2或获得性RET/FGFR等RTK改变可通过接头复合物重新加载RAS-GTP，进而维持RAF-MEK-ERK；部分RTK还同时激活PI3K-AKT。因此pERK升高是多个上游或下游机制的汇聚读数，不能据此直接指认KRAS或BRAF突变。应将受体DNA/RNA改变、配体环境、蛋白及磷酸化、原始EGFR保留情况和治疗时序一起解释。

MET拷贝数上升可包括局灶扩增或染色体多体性；血浆拷贝数还受肿瘤DNA比例影响。MET免疫组化过表达与DNA扩增检测的是不同层面，HGF配体刺激又是另一条非基因组激活途径。INSIGHT 2和SAVANNAH提供的是各自检测定义和富集人群下的联合治疗证据，不能把某个FISH、IHC或血浆阈值当作所有实验室通用的耐药确诊标准。存在低水平增益、IHC阳性或样本质量不足时，应请求方法学复核，而不是直接生成药物处方。

ERBB2激活突变、扩增和IHC蛋白表达必须拆分；它们不能互相替代HER2药物的适应证要求。获得性RET等融合要审查是否保留激酶结构域、是否为功能性融合及RNA支持，并排除另一原发肿瘤或独立克隆。RET的临床前因果与少量患者双靶反应仅支持机制匹配的试验方向；EGFR与旁路受体共存时，单独换到一个旁路靶向药也未必能覆盖全部克隆。

在奥希替尼联合化疗进展这一特定背景，以上研究多来自奥希替尼单药后的耐药人群。化疗可能改变克隆组成和组织学状态，血浆DNA也无法可靠排除小细胞转化；因此应优先对进展组织做病理、DNA及必要的RNA分析，并与治疗前样本对照。ORCHARD所示多重改变支持保留并列机制和证据不确定性，而不是让算法强行选出唯一耐药节点。FGFR/AXL等旁路在本模块仅作为待验证通路，未用下述MET或RET论文冒充其直接临床证据。

node02PTPN11 / GRB2 / SOS1 / SOS2 / NF1 / LZTR1 / PTEN

SHP2–GRB2–SOS1/2适配层：受体旁路信号的整合与RAS核苷酸循环

深入机制、标志物解释及研究性干预

EGFR被奥希替尼抑制后，其他受体酪氨酸激酶仍可经适配层维持RAS激活。GRB2是连接受体／支架蛋白与SOS的适配蛋白，SOS1/2促进RAS由GDP结合态转向GTP结合态；SHP2由PTPN11编码，参与建立完整的受体至RAS信号输出。这里的核心是多条上游信号可以汇入共享节点，而不是每一种旁路都必然依赖相同程度的SHP2或SOS1。

2025年Science Signaling研究直接考察EGFR突变肺癌的奥希替尼适应、持留及获得性耐药模型。SOS1敲除或药物抑制可减少肿瘤起始细胞并抑制适应性RAS输出，在小鼠中延缓停药后再生长。这是奥希替尼联合SOS1抑制的临床前依据；研究背景没有等同于已接受奥希替尼加化疗并在该组合上进展的临床患者，也不能把早期持留预防与进展后挽救混为同一终点。

2025年JAB-3312研究提供SHP2与奥希替尼联用在耐药NSCLC模型中的支持。临床前联合抑制可以限制RTK反馈重启ERK，但文中其他药物组合的患者代表性响应不能转记为EGFR人群的临床有效率。2023年PF-07284892临床概念验证显示某些其他驱动肿瘤在加回先前靶向药后响应，适合用作早期组合研究设计的参考，不能外推为本目标人群的成熟治疗方案。

负调控层决定上游阻断是否足够。NF1编码RAS-GAP，失活可能延长RAS-GTP状态；CRISPR筛查还显示NF1、PTEN、LZTR1等缺失可造成SHP2抑制抵抗。这意味着发现NF1缺失时，既可提出RAS通路激活假说，也必须警惕它削弱上游SHP2策略。RAS不同等位基因的核苷酸循环和上游依赖性并不相同，不能把所有KRAS、NRAS、HRAS改变套用为同一种SOS/SHP2药物敏感性。

生物标志物必须分层记录：SHP2蛋白／磷酸化升高不等于PTPN11致病活化突变；SOS1表达升高不等于已经验证的药物响应标志；pERK升高只说明下游输出，不能唯一定位到此适配层。变构SHP2药物对具体PTPN11突变的抑制作用须按药物及位点核查，不能由基因名或“致病”标签自动判断。血浆单独检出的PTPN11等变异应结合组织和必要时白细胞对照，确认肿瘤来源及与治疗相关的动态变化。

2026年Clinical Cancer Research的BI1701963±曲美替尼I期结果构成重要反证边界：机制合理不保证临床收益，摘要报告疗效有限并出现研究者判定与药物有关的致死间质性肺病。本节点因此只生成临床试验讨论与补充检测建议，不自动输出SHP2、SOS1或MEK抑制剂的个体联合处方、剂量或安全性保证。

标志物可能意义判读限制
PTPN11致病／可能致病活化变异可能改变SHP2输出，需核查具体位点、肿瘤来源、基线及进展样本，作为RAS通路参与的候选线索。不能仅凭基因名自动推断对变构SHP2抑制剂敏感；血浆低VAF变异需考虑非肿瘤来源，且暂无本目标序列的经过验证响应模型。
SHP2表达、磷酸化或pERK上调可提示信号输出或适应性重激活，适合作为实验／空间证据层补充。相关性不等于突变或因果定位，不能用IHC升高替代分子分型，也不能直接选药。
SOS1/SOS2表达、扩增或功能依赖提示研究RAS核苷酸交换依赖的方向；SOS1抑制在EGFR模型已有机制依据。没有统一临床表达或拷贝阈值可判定本目标患者获益；SOS2补偿和下游自主性改变需另行研究。
NF1明确失活、双等位基因缺失或功能丢失支持RAS负调控减弱的候选机制，结合基因型、拷贝状态和功能读出提高可信度。VUS、单一未定意义错义或仅低表达不等于功能丢失；SHP2抑制药敏不能自动从NF1缺失推出，部分模型恰提示抵抗。
GRB2／适配蛋白改变作为受体至SOS信号连接的研究层信息。未找到可据本节点文献直接用于奥希替尼加化疗后临床选药的GRB2变异标准；不将一般表达变化升级为驱动耐药。

node03KRAS

KRAS：变体、扩增与耐药克隆来源

深入机制、标志物解释及研究性干预

KRAS是受核苷酸状态控制的分子开关。EGFR等受体通过GRB2/SOS促进RAS由GDP态转向GTP态；活化RAS连接RAF二聚、MEK及ERK，从而维持增殖与存活。EGFR已被奥希替尼抑制时，获得性的致癌KRAS变体可以在下游重建通路输出。不同KRAS突变对核苷酸循环、上游输入和药物结合方式的依赖不同，不能把所有KRAS阳性事件合并为一个可用同一种药治疗的类别。N03_E01在真实奥希替尼耐药队列中发现非G12C变体的重要性，但其数据不来自奥希替尼联合化疗的独立验证队列。

关键变体必须按完整蛋白改变解释：G12C、G12D、G12V、G12R及其他位点的药理不能相互替代。G12C特异性抑制剂依赖该位点的半胱氨酸；检测到G12D或G12V不能转而推荐G12C药物。2026年Annals of Oncology的队列中，35/312是所有RAS改变的比例而非KRAS单基因比例，KRAS G12D比G12C更常见；G12D/G12R患者源模型中的奥希替尼组合结果支持研究特定选择性抑制和pan-RAS策略，不构成人体疗效保证。

KRAS扩增是与点突变不同的事件。部分耐药模型中，增加的KRAS剂量伴随ERK和AKT输出增强，KRAS敲低与RAF/EGFR联合干预可恢复药物作用；这仍主要是临床前证据。临床判读需区分局灶高水平扩增、染色体多倍体导致的拷贝数增益、肿瘤纯度影响及平台算法差异。不能用本程序设定一个适用于所有NGS、FISH和血浆检测的统一拷贝数阈值；应依据实验室经验证的判定、必要的组织正交检测和纵向变化。

检出并不等于已证明耐药因果。应比较治疗前与进展样本，保留原始EGFR驱动、KRAS变体、取样时间、检测平台、覆盖度及肿瘤来源证据。血浆中同时出现EGFR和KRAS不能证明两者来自同一个肿瘤细胞；不同病灶、第二原发、亚克隆及克隆性造血均可造成混合信号。N03_E05在EGFR突变肺癌中直接展示过血细胞来源的KRAS G12X，因此仅血液检出时应报告“候选旁路，来源待确认”，而不是直接宣布奥希替尼耐药机制已确定。

治疗解释必须保留情境。N03_E04证明以KRAS G12C为驱动的经治NSCLC存在成熟临床药物证据，但该证据不能自动成为EGFR肺癌获得性KRAS旁路中的单药或联合标准。奥希替尼和选择性KRAS、pan-RAS或RAF/MEK联合均需核对具体变体、临床试验纳入条件、脑部病灶和组合毒性；本模块不给药物剂量，也不以pERK升高或一次基因检测替代分子肿瘤讨论。

标志物可能意义判读限制
KRAS G12C（进展时新增、肿瘤来源确认）支持获得性RAS旁路的候选机制，可考虑变体匹配试验讨论。需要基线可比检测及来源确认；de novoKRAS单药证据不证明EGFR/KRAS组合有效。

node04NRAS / HRAS / NF1 / RASA1

NRAS/HRAS与NF1/RASA1：RAS开关持续激活及负调控丢失

深入机制、标志物解释及研究性干预

NRAS和HRAS是RAS小GTP酶。活化热区变异可延长GTP结合状态，使细胞在EGFR激酶被抑制后仍通过RAF-MEK-ERK维持增殖及存活。EGFR突变细胞发生NRAS Q61K等改变时，可以形成“原始EGFR驱动仍在、RAS旁路另行维持存活”的复合依赖。但NRAS热区点突变、基因扩增和mRNA表达升高是不同事件；扩增需要结合肿瘤纯度、倍性、检测平台和局灶性解释，不能用统一拷贝数阈值跨平台下结论。[N04_E01]

HRAS在奥希替尼耐药中的直接临床证据比KRAS少。PC9/AZDR细胞及动物模型同时发现HRAS G13R、MET表达升高和ERK持续活化，EGFR与MEK联用可恢复模型敏感性。这个结果支持下游MAPK活化的机制合理性，却没有排除MET等共同改变的贡献；程序应将其识别为候选旁路，不应将单个HRAS变异标成已经证实的患者耐药原因。[N04_E02]

NF1编码神经纤维瘤蛋白，RASA1编码另一类RAS GTP酶激活蛋白；二者使RAS-GTP向RAS-GDP转换，提供负调控。功能缺失会削弱RAS信号关闭。截断、经典剪接位点改变、明确功能缺失的变异或缺失可以提出RASGAP失活假说，但单个错义VUS不能这样归类；仅检测到一个致病等位基因也不自动证明完全功能丧失。拷贝数缺失、LOH、另一等位基因事件、RNA/蛋白表达和下游活性可帮助确认功能背景，但双等位基因失活仍不是现成的临床用药标志物。[N04_E03,N04_E04,N04_E05]

RASA1/NF1双失活研究必须保留人群边界：原始基因组研究中，该亚群多见于吸烟相关NSCLC，16例双截断病例缺少其他已知肺癌驱动。它建立的是另一种RAS/MAPK驱动模式及其模型药敏，不能直接证明EGFR突变肿瘤接受奥希替尼后获得RASA1/NF1改变就会出现相同机制。对进展样本应与治疗前样本配对，确认改变是获得、富集还是既存背景，同时考虑肿瘤异质性和其他可并存耐药机制。[N04_E03]

“通路活化”不能等同于“MEK抑制临床获益”。虽然NRAS相关耐药模型支持奥希替尼与MEK抑制组合，NCI-MATCH的NF1失活篮式队列总体缓解率仅4.3%，未达主要终点；2025年四例NF1改变NSCLC病例系列也未观察到明确临床获益。因此在奥希替尼加化疗耐药后的判读中，这些标志主要用于提出机制匹配试验、补充验证及分子肿瘤委员会讨论，不能自动生成MEK药物处方或剂量。[N04_E01,N04_E04,N04_E05]

血浆检出的NRAS、HRAS或NF1改变必须先确认来源。克隆性造血、另一原发肿瘤、低肿瘤含量及技术误差均可能干扰归属，不能仅凭ctDNA一次阳性或VAF升高认定为当前肺癌获得性耐药。需要结合组织病理、同一克隆的EGFR驱动、配对白细胞或正常样本、序列时间点及检测质量；血浆阴性也不能排除脑部或低释放病灶的耐药。NF1还需要区分肿瘤体细胞事件和可能的胚系事件，不能单凭接近50%的VAF作出胚系诊断。

BRAF功能分型：class I、II与III决定不同的RAS依赖和联合治疗边界

深入机制、标志物解释及研究性干预

BRAF是RAS与MEK之间的RAF家族节点，但“检出BRAF改变”不能单独判定为同一种耐药。Class I中的典型BRAF V600E可作为RAS非依赖的活性单体输出MAPK信号，理论上在EGFR被抑制时继续激活MEK/ERK。与此不同，class II通常依赖组成性活性二聚体；class III则不是简单的强激酶激活，而是低活性或失活BRAF借助已有RAS-GTP与CRAF放大信号。这些差异使同一个BRAF基因上的不同变异不应共用一个药物规则。

功能分型必须基于具体蛋白变异和已验证的生物学，不可把所有G469、D594、所有非V600变异或未注释VUS仅按基因名自动归类。BRAF V600E与D594N同时存在时，可能涉及不同克隆、同一等位基因复合改变或不同病灶的混合信号；bulk测序不能自行完成相位与共克隆性判断。应保留基线阴性/阳性、进展组织DNA与必要时RNA、ctDNA肿瘤来源、肿瘤含量及多个病灶信息，才能评估这条通路是否是新的主导旁路而非既有亚克隆。

Class II的活性二聚体使针对单体BRAF的药物未必充分抑制，且部分RAF抑制背景可能出现反常MAPK激活；class III往往需要上游RTK、RAS激活或NF1缺失等共同条件。因此更合理的研究问题是识别RAS依赖来源、RAF二聚体及下游药敏，而不是将BRAF V600E驱动NSCLC的既有治疗经验推广到所有BRAF异常。Pan-RAF、RAF二聚体、MEK/ERK或上游适配蛋白等联合策略都需说明具体模型、临床阶段与毒性，不在此生成个体处方。

BRAF融合、RAF1/ARAF与RAF二聚体：结构变异和旁路依赖

深入机制、标志物解释及研究性干预

BRAF融合与V600E点突变是不同的分子事件。典型致癌融合保留3端BRAF激酶结构域，并可能去除N端调控区域或借助融合伴侣改变二聚化和定位，使RAF–MEK–ERK在EGFR被抑制时仍保持活性。许多融合具有二聚体相关的生物学特征，但不能仅凭“BRAF融合”四字就判定所有伴侣、断点和RAS依赖性相同。Vojnic等的患者耐药样本、CRISPR和患者衍生模型支持AGK/PJA2-BRAF作为EGFR-TKI获得性耐药机制；其中奥希替尼联合MEK抑制、以及pan-RAF策略的关键支持来自实验模型。

程序判读必须先审查结构，而非把所有DNA rearrangement都作为可治疗融合。重要字段包括融合方向、精确断点、是否同框、是否保留完整激酶结构域，以及RNA表达和正交证实。DNA检测到间隔区断点、低支持读段或无法解释的伴侣时应输出待确认；RNA阴性也需结合样本质量及检测覆盖。进展时新增而基线足够敏感检测未见的融合，更支持获得性事件，但血浆中与EGFR同时存在不等于两者位于同一克隆。应结合组织、分时点ctDNA、肿瘤负荷和必要的克隆研究。

RAS/BRAF并非独立封闭的串联开关。相同的受体或黏附信号可同时连接MAPK与PI3K–AKT存活分支：2017年的EGFR突变肺癌模型显示，SFK/FAK在持续EGFR抑制下仍可维持AKT和MAPK输出，且YES1扩增可参与奥希替尼耐药。因而pERK升高只是某时点的下游读出，不能唯一定位为KRAS、BRAF或MEK基因改变；同样，检测到一个MAPK事件也不能排除平行AKT存活轴。程序应分别记录DNA变异、拷贝数、蛋白磷酸化及功能证据，并检查它们是否来自同一病灶和治疗阶段。

AXL提供一个适应性网络范例。奥希替尼可通过解除负反馈增强AXL活性，AXL与EGFR/HER3相关的存活信号能够帮助耐受细胞出现；这既可能表现为无新增驱动DNA变异的状态，也可能与后续遗传耐药并存。AXL总蛋白、磷酸化、RNA及具体位点突变不是同一种检测结果。2026年的AXL位点图谱进一步把FAK1、SFK/ABL相关信号和YAP1连接起来，但其功能与临床关联主要来自厄洛替尼背景，不能以“均为EGFR-TKI”替代对奥希替尼加化疗后队列的验证。

整合素/ECM—ILK—SFK—YAP轴体现了细胞状态的另一层耐药。2025年研究用遗传与药理干预支持ILK参与EMT、YAP激活及药物耐受持留，并观察到人体标本关联。它说明持续存活可以早于明确的新增耐药驱动，并给后续克隆演化留下空间。然而早期持留、可逆状态与进展时稳定获得性耐药应分开判读；YAP核定位或EMT签名不能直接宣布某患者对YAP/TEAD药物敏感，更不构成把多条通路同时抑制的依据。

PI3K/AKT/mTOR也可能有独立遗传驱动：特殊de novo EGFR T790M病例系列及功能实验识别了MTOR L1433S，支持该特定改变经AKT旁路影响奥希替尼敏感性。该发现不能泛化成任意MTOR变异、单个PIK3CA意义未明变异或单纯pAKT升高。NF1/PTEN等改变还可能影响其他试验性抑制剂的响应方向。因此程序应保留位点、致病分级、双等位状态（适用时）、获得性和功能验证，不用“通路上游/下游”位置代替实际药敏证据。

总体判读必须允许多机制并存：血浆出现RAS/BRAF改变，组织中同时存在MET扩增、EMT或小细胞转化，并不证明所有异常在同一克隆内。需要治疗前后对照、同一进展病灶的病理与DNA/RNA、必要的蛋白和空间验证；脑部或寡进展还应评估药物暴露与取样代表性。这五篇均未提供专门针对奥希替尼联合化疗耐药后人群的随机疗效验证，故适合生成机制假设、补充检测和试验讨论路线，不适合自动处方。

临床背景、纵向取样与克隆：将通路异常放回奥希替尼＋化疗后的人群

深入机制、标志物解释及研究性干预

耐药机制判读应从治疗序列开始：是否真正同时使用奥希替尼与铂类/培美曲塞、何时进展、既往是否已接受埃万妥单抗或ADC，都会改变能否外推研究结果。FLAURA2原始随机试验属于一线疗效证据，不是某个RAS/BRAF耐药事件的功能或匹配用药证据。既往接受过奥希替尼、之后再接受化疗，也不能自动标记成“一线奥希替尼＋化疗后”研究人群。

进展时尽量将病灶组织病理与DNA/RNA检测、血浆ctDNA以及基线资料放在同一时间轴。OSIRIS显示组织与血浆检测具有互补性；血浆阴性、没有检出EGFR创始突变或检测报告仅含低丰度信号，都可能反映低肿瘤释放、平台覆盖或取样问题，不能证明不存在RAS/BRAF旁路。拷贝数、融合和组织学状态尤其不能只依靠一次血浆面板排除。

组织学变化是独立的决策分支。Schoenfeld配对组织研究显示鳞状等转化可与新的离靶改变并存。TP53/RB1共改变只能提出转化风险，不能替代小细胞或其他组织学诊断；即便仍检出EGFR或MAPK相关变异，也不能忽略病理已转化这一更直接的治疗背景。程序应优先提示补取病理和多学科复核，不把所有进展都归结为同一个MAPK抑制问题。

同一次bulk测序中检测到EGFR与KRAS/BRAF，并不证明两者位于同一肿瘤克隆，也不证明后者一定为获得性事件。MATCH-R仅在其可分析的4份单细胞样本中证实双驱动共存，并展示显著异质性；这支持逐例验证的必要性。没有合格基线对照时应将acquired保留为unknown，不能仅因报告日期较晚就设为新出现；治疗前已有的改变还需区别原发耐受、克隆扩张和旁观事件。

进展模式同样影响解释。全身多部位进展、少数病灶寡进展、孤立脑实质或脑膜进展不能混用一套规则。中枢庇护区或局部耐药克隆可使血浆信号不能代表关键病灶；是否采用局部治疗、补充脑脊液或组织检测需依据临床指征和安全性由多学科团队讨论。pERK/pMEK升高只是通路输出，不定位到RAS、BRAF或某个上游受体；DNA/RNA、病理与取样语境必须共同解释。
