# 子任务 5：MAPK 交叉通路、旁路融合与细胞可塑性

整理日期：2026-10-30。目标文献窗口为 **2016-10-30 至 2026-10-30**。本文件研究 EGFR 突变 NSCLC 中 PI3K/AKT/mTOR 与 RAS/MAPK、替代受体、YAP/EMT 和组织转化的联系，服务于研究型规则引擎。

## 1. 为什么必须把这些节点放在同一个判读框架

PI3K/AKT 与 RAS/RAF/MEK/ERK 通常共享上游受体和适配蛋白。MET、ERBB 家族或功能性融合激酶可以同时增加两条支路的输出；因此 pAKT 与 pERK 同时升高不证明存在两个独立耐药机制，也不能推导需同时叠加两种下游药物。反过来，抑制一条支路后的反馈可能使另一条支路成为重要生存来源。[C01–C04]

细胞状态还会改变凋亡阈值、受体谱和基因表达。AXL、YAP/TEAD 或 EMT 线索并不要求 DNA 中出现新突变。常规 DNA panel 阴性无法排除这些过程。组织学转化则需要病理优先：即使原 EGFR 突变仍在，也不能据此认定肿瘤仍按腺癌的原有药物依赖方式生存。[C05–C08]

## 2. 节点级研究与检测矩阵

| 节点/状态 | 与 PI3K/AKT/mTOR 的联系 | 有价值的证据 | 关键误判与研究干预边界 |
|---|---|---|---|
| KRAS/NRAS | RAS–RAF–MEK–ERK 可维持增殖；某些背景也与 PI3K 输出相连 | 具体等位基因、功能注释、治疗前后 DNA、克隆结构、pERK/pAKT | 任意 RAS VUS 不是激活；低 VAF 不是主导因果。G12C 药物不能套用其他等位基因。是否需同时控制 EGFR 必须另证实 |
| BRAF V600E | 下游 MAPK 持续输出，可能绕过上游受体抑制 | 明确位点、前后配对、克隆及功能线索 | V600E 与非 V600 不能按同一药敏分类；BRAF/MEK 在独立 BRAF 驱动癌中的证据不证明奥希替尼三药组合在目标人群有效 |
| 非 V600 BRAF | 功能类别决定二聚体/RAS 依赖；不能仅由基因名判断 | 变异级功能分类，必要时模型验证 | II/III 类与 V600 的药敏不同；某些 RAF 抑制背景可反常激活 MAPK |
| BRAF 融合 | 融合可导致调控丢失与二聚化，维持 MAPK | DNA 重排加 RNA 表达/同框、断点、激酶域保留；与 EGFR 肿瘤同源关系 | 融合不等于 V600E；EGFR＋MEK/新 RAF 组合主要是研究路径，不能赋予常规处方地位。[C02] |
| PTPN11/SHP2、SOS1 | 在许多 RTK–RAS 输入间传递信号；阻断可能限制适应性反馈 | 通路功能、受体依赖、RAS 等位基因、药效模型 | 不同 RAS 变异的上游依赖不同；PTPN11 变异或 SHP2 表达不自动预测药物敏感。不能声称所有 KRAS 耐药均可用 SHP2 逆转 |
| FGFR1/2/3 | RTK 可经 FRS2 等适配连接 MAPK 与 PI3K；扩增、融合、自分泌属于不同事件 | 基因拷贝数和纯度；RNA 融合；必要时受体磷酸化/配体/依赖验证 | FGFR 扩增不一定产生依赖；不能把多个亚型的事件合成一种发生率或药敏。其他癌种 FGFR 标签不能直接外推 |
| RET/ALK/NTRK 功能融合 | 新激酶信号可同时进入 MAPK 和 PI3K；部分克隆仍依赖 EGFR | 进展组织 DNA＋RNA、同框和激酶域、基线样本、病理；ALK 可加 IHC/FISH | DNA 重排、单纯蛋白阳性、非功能融合要分开。需排除第二原发和混合样本。EGFR 双靶向人体证据规模及适应证均需独立审查。[C03,C04] |
| AXL/GAS6 | 受体交叉、AKT/MAPK 生存及耐受状态有关 | 肿瘤细胞 AXL/pAXL、RNA、EMT/状态指标；配对组织和功能抑制 | 高表达不是因果；IHC 需区分肿瘤和基质，未建立通用临床阈值。内在耐受不等于获得耐药。[C06] |
| YAP/TEAD | 转录重编程改变生存与凋亡阈值，可参与治疗诱导休眠/持留 | 核定位、TEAD 靶基因、配对 RNA/蛋白、功能实验 | 不能用总 YAP 表达或单一 DNA 事件推断依赖；YAP/TEAD 抑制是研究方向，不能据休眠模型给出目标人群临床疗效。[C07] |
| EMT/持留细胞 | 上皮谱向间质谱漂移可改变受体依赖、药物耐受和凋亡 | 配对组织病理、RNA 状态、E-cadherin/vimentin 等组合和肿瘤纯度 | 单一 vimentin 阳性可能来自基质；EMT 不等于小细胞转化，不是一个已验证靶药标志物 |
| 小细胞/鳞状等转化 | 谱系变化可使 EGFR 基因保留而原依赖减弱；PI3K 信号可伴随但未必主导 | 进展组织病理、形态、适当神经内分泌/鳞状标志，原克隆关系 | RB1/TP53 共失活提示风险，不能代替病理诊断。血浆不能排除组织转化；转化后治疗研究需另按病理、人群及既往化疗审查。[C05,C08] |

这些检测是互补层面，不是自动执行的临床检验套餐。是否取样及如何解释需要临床、病理和分子团队共同决定。

## 4. 建议整合的 5 条可编码规则

所有规则的“命中”表示研究线索。除非存在独立功能验证和匹配临床证据，不输出“已证实主导耐药机制”或自动处方。所有依赖上述来源的治疗提示须携带 `source_verification = not_online_verified` 以及 `post_osimertinib_plus_chemotherapy_validation = not_established`。

### X01：特定 MAPK 激活改变

- **触发：** 进展标本中检出已注释为功能性激活的 KRAS/NRAS/BRAF 改变；BRAF 融合还需可信 RNA 表达/同框和激酶域证据。VUS 或仅基因名不触发阳性机制。
- **输出：** `candidate_mapk_bypass_or_reactivation`，并把 BRAF V600、非 V600 和融合分开。基线存在时标记 `pre_existing_or_selected`；只有可靠基线阴性才可标记 `newly_detected_after_treatment`，仍不等于绝对新生或因果。
- **确认：** 前后配对、标本及纯度、VAF/拷贝数、原 EGFR 克隆、病灶分布和功能依据。[C01,C02]
- **治疗研究提示：** 按具体改变查询 RAS/RAF/MEK/ERK 与 EGFR 的研究；不自动选药、不把三药组合当已验证标准。

### X02：新融合 RTK 交叉输入

- **触发：** RET/ALK/NTRK/FGFR 等重排首先输出 `fusion_confirmation_needed`；具备可信 RNA/正交支持及合理结构后才升级为 `candidate_fusion_bypass`。DNA panel 阴性不排除覆盖不足导致的融合漏检。
- **输出与确认：** 记录激酶基因、伙伴、同框、表达、断点、原驱动及病理；排除第二原发、样本混合、非功能事件。是否与 EGFR 同一克隆通常不能仅靠同一管样本断定。[C03,C04]
- **治疗研究提示：** 查询事件特异的匹配临床研究；独立融合驱动病的单药批准不能自动升级该继发联合。FGFR/ALK/RET/NTRK 不共用同一证据等级。

### X03：AXL/EMT/YAP 状态线索

- **触发：** AXL/pAXL、YAP 核定位/TEAD 转录、EMT 多指标等可信状态证据；单一蛋白总表达或 DNA 阴性不构成排除/确诊。
- **输出：** `non_genomic_state_signal`，不得输出具体因果机制的高置信度。肿瘤细胞与基质表达不明时降为 `insufficient_context`。
- **确认：** 治疗前后组织、IHC/RNA 状态组合、技术及肿瘤纯度、必要时功能干预；记录是否仅内在耐受模型外推。[C06,C07]
- **治疗研究提示：** AXL、SHP2/SOS1、TEAD 等仅作为研究检索方向；不得因通路关联推断全部药物联合都有活性。

### X04：阴性 DNA/血浆结果的保护规则

- **触发：** 输入标本是血浆，或 DNA 阴性/无可行动变异，但缺少肿瘤释放/检测灵敏度信息、RNA 或进展病理。
- **输出：** `mechanism_unresolved` 及采样/检测缺口；不输出 `no_resistance_mechanism` 或 `pi3k_pathway_inactive`。
- **确认：** 根据可行性补充进展组织、病理、RNA/拷贝数/蛋白状态等互补检测。不能把建议检测变成无条件必须侵入性活检。[C03–C07]
- **治疗研究提示：** 不为“未检出”生成一个确定的 PI3K/AKT/mTOR 药物匹配。

### X05：病理转化优先分支

- **触发：** 有合格的进展组织病理明确小细胞、神经内分泌或鳞状转化。只有 RB1/TP53 改变或血浆信号时不触发确诊。
- **输出：** `histology_transformation_detected`，作为优先的分层/转诊复核事项，同时保留可能并存的其他克隆机制。原 EGFR 仍阳性不取消该输出。
- **确认：** 病理复核、适当标志物、基线对比及肿瘤同源性；并存原发/混合组织需明确。[C05,C08]
- **治疗研究提示：** 按转化病理和既往铂类暴露查询治疗及试验；不沿腺癌 PI3K 信号直接输出三药/四药方案，不以未经核验资料宣称标准或获批。

## 5. 必须保留的负规则

1. `pAKT_high && pERK_high` 不等于两个独立主导耐药克隆，不触发自动多药叠加。
2. `AXL_expression_high`、`YAP_expression_high`、`vimentin_positive` 均不能单独确定目标依赖；蛋白表达与磷酸化不能互换。
3. `RB1_loss && TP53_loss` 不能等同 `small_cell_transformation = true`。
4. `BRAF_fusion` 不能映射为 `BRAF_V600E`；`RAS_variant_unknown` 不能映射为已知激活位点。
5. `plasma_DNA_negative` 不能排除组织转化、低释放克隆、融合、拷贝数改变或非基因组耐受。
6. `response_in_preclinical_model`、`response_after_osimertinib_monotherapy` 和 `approved_in_other_driver_population` 均不能升级为奥希替尼＋化疗进展后的疗效结论。
