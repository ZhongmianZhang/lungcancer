# 子任务 4：mTOR 复合体、翻译输出、反馈与自噬

研究问题：EGFR 突变 NSCLC 在奥希替尼联合化疗后进展时，MTOR、mTORC1/2 及其输出能否构成耐药解释，并能否支持匹配治疗研究。

整理日期：2026-10-30。目标证据窗口：2016-10-30 至 2026-10-30。**本文件所有列出的来源均未在线核验**：本次环境的医学网站访问被策略拒绝，未完成数据库实时检索、全文/补充材料检查或会议摘要逐项定位。下文不是完整十年系统综述，不能把整理日期作为检索覆盖截止日期；文献可识别与其支持某一具体结论是两回事。

## 结论与证据边界

mTOR 是连接生长因子、营养、能量状态和蛋白翻译的信号枢纽，具有作为残余存活/耐药输出的生物学合理性。**通路输出持续，并不等于某个 mTOR 基因改变是驱动机制，也不等于 mTOR 抑制能改善临床结局。**

本子任务未能定位并核验：以“奥希替尼＋铂类/培美曲塞后进展”为入组条件、按 MTOR/RICTOR 或磷酸化标志物筛选并前瞻性验证 mTOR 匹配药物的原始临床研究。不能使用奥希替尼单药细胞模型、EGFR 野生型肺癌 RICTOR 研究、其他癌种药物批准或 FLAURA2 的总体疗效填补这一证据空缺。

因此，下面的可编码输出最高为“待功能确认的候选机制”和“临床试验研究方向”。本文件不建立发生率、不计算致病概率、不宣称该人群存在已验证的 mTOR 特异救援方案。

## 节点与检测解释

| 节点/输出 | 生物学关系 | 可用证据 | 关键误判及确认要求 |
|---|---|---|---|
| MTOR | mTORC1 与 mTORC2 的催化核心 | 组织/血浆 DNA；变异级功能研究；下游输出 | 并非所有错义变异均激活；VUS 不能等同于耐药驱动；功能性变异也不能单独证明本次进展由它驱动 |
| RPTOR | mTORC1 支架/底物募集 | RNA/蛋白、复合体/功能研究 | 表达增加不等于功能增强；任意 RPTOR 变异不可直接变成治疗匹配规则 |
| RHEB | TSC1/2 下游小 GTP 酶；GTP 状态参与激活 mTORC1 | 变异级功能、TSC 状态、营养/定位相关研究 | RHEB 表达、DNA 改变和活性不是同一指标；仅依据基因名无法预测药敏 |
| RICTOR / MAPKAP1(SIN1) | mTORC2 核心组成，关联 AKT S473、SGK/PKC 等输出 | 拷贝数并结合纯度/倍体、RNA/蛋白、pAKT S473、功能依赖 | 低水平拷贝数增益/多倍体不等于局灶高扩增；RICTOR 高表达也不必然说明 mTORC2 依赖 |
| AKT T308 与 S473 | T308 主要联系 PDPK1；S473 常联系 mTORC2；磷酸化状态共同参与调控 | 配对磷酸化和总蛋白、采样前处理记录、动态药效研究 | S473 阳性不是 RICTOR 扩增或 mTORC2 独立驱动的特异诊断；单一时点不能区分上游输入、反馈和新耐药 |
| RPS6KB1/2(S6K1/2) → RPS6 | mTORC1 的一支翻译/生长输出 | pS6K T389、pS6 S240/244 与 S235/236 等 | S235/236 亦可受 MAPK–RSK 输入；pS6 阳性不能独自定位 mTOR 机制；多个位点与总蛋白、上游背景须联合解释 |
| EIF4EBP1 → EIF4E | 4E-BP1 磷酸化可解除对 eIF4E 的抑制，促进帽依赖翻译 | 多位点 p4E-BP1、总蛋白、eIF4F 形成及翻译输出实验 | 不能将 p4E-BP1 一个抗体结果当作功能性完全失抑制；不同位点、底物敏感性和细胞周期背景不同 |
| MKNK1/2 → EIF4E S209 | MAPK 与翻译的交叉输出 | pERK、pMNK、pEIF4E 和功能研究 | pEIF4E S209 不是 mTOR 特异读出；应保留 MAPK–MNK 交叉通路解释 |
| ULK1 / 自噬系统 | mTORC1 抑制 ULK1 相关自噬启动；自噬可参与压力适应 | 动态通量实验、溶酶体阻断前后 LC3/p62 变化、功能扰动 | 静态 LC3B 或 p62 升高不能证明自噬通量增加；也可能反映降解阻塞，不能据此开出自噬抑制组合 |

上述检测没有在本库设定跨平台通用阈值。磷酸化/IHC 需要样本缺血时间、固定方式、批次、阳性/阴性对照及总蛋白归一化；血浆 DNA 阴性无法排除蛋白状态型激活。RNA/转录组的通路富集属于间接支持，不能替代激酶活性和因果性验证。

## 耐药构型与必要的竞争解释

1. **上游旁路继续输入。** MET、HER2/ERBB3、IGF1R/INSR 等可以使 AKT–mTOR 输出持续。此时 mTOR 激活可能是共同终端读出，候选主导节点应结合受体改变及干预后输出决定，避免同时把每层都计为独立驱动。
2. **PI3K/AKT 或负调控改变。** PIK3CA/AKT 功能性激活、PTEN 失活、TSC 失活等可抵消 EGFR 关闭；每一项需基线与进展样本、克隆/纯度信息及功能证据。详见相应子任务，不能仅凭通路连接推定双等位失活或药敏。
3. **mTORC1/2 本体改变。** 已有肺癌 RICTOR 研究提供 mTORC2 依赖的研究线索，但不能假定其适用于 EGFR 突变且经历化疗的人群。MTOR 的具体变异、RICTOR 局灶扩增和表达性变化应分别报告。
4. **反馈与旁路重布线。** 持续抑制 mTORC1/S6K 可解除 IRS1 等负反馈，使上游输入和 AKT 或 ERK 回升；观察到药后 pAKT 增加可能是反馈，而非新出现的基因组耐药驱动。药效采样须明确治疗暴露与时间点。
5. **翻译和细胞状态适应。** MAPK–MNK–eIF4E、帽依赖翻译、应激翻译、自噬等可能支持持留细胞。须用多模态或功能研究区别存活相关性与必要依赖，亦需排除组织学转化、多克隆进展和药物暴露不足。

联合化疗本身增加选择压力和细胞状态异质性，不能预设联合方案后耐药谱与单药完全一致。进展样本还可能富集对化疗的耐受机制；不能把全部进展归因于原 EGFR 信号恢复。

## 候选干预的研究属性

| 研究策略 | 生物学目的 | 本情境治疗证据与限制 |
|---|---|---|
| Rapalog 类，如 everolimus/temsirolimus | 变构抑制 mTORC1 的部分功能 | 不应假定全面阻断所有 mTORC1 底物；不同情境中可有反馈回升，长期暴露对 mTORC2 的影响也有细胞背景差异。本库未核实该组合后进展人群的匹配临床获益 |
| ATP 竞争性 mTOR 激酶抑制剂，如 sapanisertib、vistusertib 等研究药物 | 同时影响 mTORC1/2 催化功能 | 与 rapalog 的药理不能互换；体外双复合体抑制不证明可耐受暴露或临床获益。本库不认定其为该情境标准治疗 |
| 双 PI3K/mTOR 抑制研究 | 减少上游反馈与双层信号补偿 | 更广靶谱不等于更优治疗窗；糖代谢、皮肤/胃肠道、黏膜、感染和肺部毒性等可能限制与 EGFR/化疗组合 |
| EGFR 与已确认主导旁路联合研究 | 同时限制原 EGFR 与受体旁路输入 | 上游受体选择须依据改变和该继发情境的临床证据；不能因 pS6 高就叠加多层药物 |
| 4E-BP/eIF4F、eIF4A、MNK 或自噬干预研究 | 降低终端翻译/压力适应 | 属需要独立证据与功能依赖验证的研究方向；不以表达或静态 LC3B 染色直接分配治疗 |

不提供联合剂量。其他癌种批准、单药说明书和前临床协同都不能代替本情境联合的疗效、安全性与当地现行标签。

## 五条可编码规则

1. **MTOR 变异规则。** 输入为具体 MTOR 变异，且有可追溯的变异级激活功能证据，才能输出“MTOR 激活候选”。仅 gene=MTOR、VUS、未验证错义变异或表达升高输出“证据不足”，不得匹配药物。即便激活功能已知，仍需基线/进展、克隆结构和蛋白输出；不输出“已确认本次耐药原因”。
2. **RICTOR 拷贝数规则。** 只有经实验室解释为局灶高水平扩增，且具纯度/倍体校正或正交支持时，输出“mTORC2 依赖待验证候选”；低水平 gain、染色体多倍体或未知阈值输出“不可据此判定”。提示补充 RNA/蛋白、pAKT S473 与 T308、原 EGFR/旁路并存状态。治疗栏为试验研究方向，证据来源人群须显示“肺癌背景，非该组合后验证”。
3. **磷酸化输出规则。** pS6/p4E-BP1/pAKT 任一单项升高，仅输出“通路输出线索”。多位点、一致的总蛋白归一化与配对时间点可加强输出持续的解释，但不转换成某一特定基因驱动，也不直接升为临床可行动。pS6 S235/236 与 pEIF4E S209 必须提示 MAPK–RSK/MNK 竞争解释。
4. **反馈规则。** 若 pAKT/pERK 的升高发生于 mTORC1 抑制暴露之后，输出“反馈重激活待验证”，避免自动归为新获得 RICTOR/AKT 基因组耐药。要求记录暴露/采样时间、治疗前后同平台检测及上游受体状态，不自动增加药物数量。
5. **自噬/翻译规则。** 静态 LC3B/p62、RNA 通路评分或 eIF4E 表达单独作为输入时，输出“间接/非特异证据，不足以认定依赖”。有通量与功能扰动证据时可输出实验研究假设；治疗栏不得形成常规自噬/翻译抑制处方。

这些规则是研究分层与缺口提示，不是经过临床效能验证的诊断算法。
