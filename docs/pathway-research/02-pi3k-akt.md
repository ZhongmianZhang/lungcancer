# 子任务 02：PI3K–PDPK1–AKT 节点

目标人群：EGFR 突变 NSCLC 接受奥希替尼联合化疗后进展。资料时间窗口为 **2016-10-30 至 2026-10-30**。下列为可追溯的研究线索及可编码规则；本次无法在线访问医学数据库，**所有文献题录、全文、当前试验状态及 2025–2026 更新均未在线核验**。本文件不是十年系统检索的结果；没有定位到的研究不等于不存在。

## 结论与适用边界

PIK3CA 激活、PTEN 功能丢失以及上游受体输入，均可能维持 PI3K–AKT 生存信号。但有三个不同问题：某节点存在生物学活化；它是否驱动当前病灶耐药；针对该节点是否改善这个治疗背景下患者的临床结局。三者不能合并为一个“阳性”判断。

FLAURA、AURA3 和组织耐药系列可以支持 **EGFR-TKI/奥希替尼后候选通路事件**；它们不直接证明“奥希替尼＋化疗后”的机制比例或 PI3K/AKT 联合方案疗效。PI3K/AKT 抑制剂在乳腺癌及跨癌种篮式研究的活性，是药物可作用于某些分子背景的依据，不能写成 EGFR 突变肺癌耐药后的标准处方。本次资料没有建立该特定联合耐药人群中经过前瞻性验证的 PI3K/AKT 常规匹配方案。

## 节点与检测解释

| 节点 | 应分别记录的事件 | 生物学及需要确认的内容 | 不能自动推导的结论 |
|---|---|---|---|
| PIK3CA / p110α | E542K、E545K、H1047R/H1047L 等已知激活变异；其他明确功能变异；拷贝数扩增；VUS | 螺旋域与激酶域变异的调控背景不同；记录转录本/HGVS、覆盖、VAF、肿瘤纯度、拷贝数及等位状态；比较治疗前后样本与原 EGFR 克隆 | 任意 PIK3CA 变异都激活；激活变异必是新获得性；扩增与热点突变是相同药物标志物 |
| PIK3CB / p110β | 扩增、明确功能性激活变异、表达变化 | 某些 PTEN 缺失模型存在 PI3Kβ 依赖；需在具体 EGFR 肿瘤模型/样本中证实，不能只凭 PTEN 阴性决定亚型药物 | PTEN 缺失一律依赖 p110β；PIK3CB 阳性可套用 alpelisib 的 PIK3CA 乳腺癌证据 |
| PIK3R1 / p85α | 具体错义/缺失/截短、双等位状态 | p85 调节亚基的不同变异可能解除调控，也可能有其他作用；需要变异级功能注释 | 任意 PIK3R1 截短都等同 p110α 激活；基因名级“致病”注释足以预测药物敏感 |
| PDPK1 / PDK1 | 明确功能变异、拷贝数/表达、PDK1 及底物磷酸化 | PDK1 参与 AKT T308 磷酸化；同名缩写不能与丙酮酸脱氢酶激酶 PDK1 混淆。需用 HGNC 符号 PDPK1 | 蛋白高表达即为主要驱动；可直接由此匹配获批药物 |
| AKT1 | E17K、其他已验证功能变异；扩增；pAKT | E17K 可改变 PH 域膜定位，是可追溯篮式研究标志物；其跨癌种证据并非奥希替尼＋化疗耐药的特异证据 | 所有 AKT1 变异均类似 E17K；E17K 必是耐药新生；跨癌种单臂活性等于本场景获批 |
| AKT2、AKT3 | 各自的明确功能变异、拷贝数、RNA/蛋白 | 家族成员不能互换；扩增/表达需区分亚型、肿瘤细胞与间质来源，并寻求功能确认 | 任意 AKT2/3 事件可套用 AKT1 E17K 的响应数据 |
| AKT 输出 | pAKT T308、pAKT S473；PRAS40/FOXO/GSK3 等底物；下游 pS6/4EBP1 | T308 与 S473 对应不同调控输入；取样时间、固定缺血、抗体/评分、正常内对照、治疗暴露和肿瘤细胞定位必须记录 | 单一 pAKT 或 pS6 阳性可定位上游具体基因；任意 pAKT 升高意味着 AKT 抑制剂无效 |

基因型与磷酸化结果应保留为两条证据，而非互相覆盖。ATP 竞争性 AKT 抑制剂可产生与反馈/药物结合相关的 pAKT 增高；药效应结合下游底物和临床状态判断，不能仅凭一个磷酸化位点宣告信号恢复或药物失败。

## 从进展样本到候选机制

1. 确认输入来自**肿瘤进展时点**，记录取样病灶、组织/血浆、治疗时间线与是否持续用药。若实际先用奥希替尼、后用化疗，应与一线同时联合标记为不同背景。
2. 对基因组事件记录变异级意义、质量、治疗前同一事件状态及原 EGFR 驱动。治疗前同位点已有变异属于预存/共存事件；VAF 上升还可能来自纯度、拷贝数、脱落差异，不能直接等同克隆选择。
3. 治疗前阴性仅在样本适用、位点可检、覆盖足够且检测灵敏度已知时，支持“治疗后首次检出”；它仍不能区分真正新生与原有低频亚克隆。
4. 新检出 PIK3CA 热点且通路输出一致时，可列为候选下游再激活机制；如果 MET/ERBB2/RAS 等机制并存，应保留共同驱动和旁观者的可能，不能把所有事件强行排列为唯一病因。
5. 血浆阴性不能排除组织、拷贝数或非基因组激活。血浆结果也不能排除小细胞/鳞状转化；需要病理重评的信号不应被通路阳性结果掩盖。

## 干预证据如何进入工具

| 研究方向 | 可显示的内容 | 在本场景中的限定 |
|---|---|---|
| p110α 选择性抑制（如 alpelisib） | PIK3CA 特定背景下的抑制机制和其他癌种的研究/批准边界 | 不把乳腺癌标签迁移为 EGFR NSCLC 耐药标签；PIK3CA 阳性仍需判断依赖、反馈与合并 PTEN/RTK/MAPK 事件 |
| pan/class-I PI3K 或其他亚型抑制 | 按事件与亚型检索研究，不设为“PI3K 阳性通用药” | 肺癌历史研究存在有限活性/未达到预设目标；不能只收集阳性案例。PI3Kβ 假说尤其需要功能证据 |
| AKT 抑制（如 capivasertib；其他研究药另行核验） | AKT1 E17K 跨癌种试验、乳腺癌随机研究及候选 EGFR 联合研究方向 | 试验人群、联合伴侣和治疗线次不相同；不能输出奥希替尼＋AKT 抑制剂为标准疗法 |
| EGFR 与 PI3K/AKT 联合 | 保留 EGFR 依赖与新通路依赖的机制假说，优先寻找明确标志物临床试验 | 没有经核验的本场景人群疗效时列“研究性候选”；不给剂量、不以体外协同预测患者响应 |
| 多层级 PI3K/AKT/mTOR 联合或加化疗 | 耐药模型中的补偿与潜在协同 | 不由多个节点同时活化推导多药叠加；三/四药治疗窗、药代与骨髓/代谢/肺毒性必须有独立证据 |

PI3K/AKT 药物常见关注点包括高血糖、皮疹、腹泻等；不同药物还可有肝毒性、感染等风险。与 EGFR 药物和化疗的相互作用、间质性肺病及骨髓抑制等风险应按具体药物/方案核对。风险列表用于提示查证，不提供个人用药/监测处方。不能因为有其他癌种批准就标记为“安全可联合”。

### 目前的文献和会议缺口

- 需要在线定位专门检验 PIK3CA/AKT 改变导致奥希替尼耐药、并通过特异性抑制/遗传救援逆转的近年原始模型研究；在题录和实验对象不确定时，不编造标题或将其列为已核实的“奥希替尼＋capivasertib”证据。
- 需要检索 FLAURA2 及其他奥希替尼联合铂类/培美曲塞研究的成对进展样本、PI3K/AKT 基因组和磷酸化结果。单药研究的机制比例不能作为替代。
- 需要在 ASCO、ESMO、AACR、IASLC/WCLC 的正式摘要集中查找相关进展样本及早期联合研究；本次没有可以负责任地提供的**已核验摘要号**。不得把期刊研究后续的会议展示重复计为独立队列。
- 对所有候选研究，核对是否为真正进展后治疗试验、研究人群是否 EGFR 突变且暴露于奥希替尼＋化疗、是否按 PIK3CA/AKT 选择、研究是否早停，以及临床浓度是否达到模型中的有效暴露。

## 建议给判读引擎的 5 条规则

1. **PIK3CA 已知激活变异**：触发条件是质量合格的肿瘤进展样本检出经过变异级注释的激活变异（初版可明确列 E542K、E545K、H1047R、H1047L）。输出“候选 PI3K 下游再激活”，附 PA01–PA03 和背景迁移标志；基线已有则标“预存/共存，不能证明获得性”；基线可检且阴性则标“治疗后首次检出，尚不能证明新生”。研究治疗线索单独列，不能输出常规 alpelisib 处方。
2. **PIK3CA/PIK3CB/PIK3R1 VUS 或未经确认扩增**：只触发“待解释事件/需确认”，不升级到通路激活或药物匹配。拷贝数需确认局灶性、纯度/倍体和功能输出，PIK3R1 需变异级功能依据。输入的 `pathogenic` 注释须说明指向癌症功能还是其他遗传病，不能无条件信任基因名级分类。
3. **AKT1 E17K 与其他 AKT 事件分离**：高质量 E17K 输出“候选 AKT 激活，有跨癌种间接治疗研究（PA05）”；AKT2/AKT3 扩增、未知 AKT1 变异不得触发 E17K 特异性证据。全部保留“本联合耐药人群尚未直接验证”的输出字段。
4. **磷酸化信号**：经肿瘤细胞定位、内对照和前处理质量控制的 pAKT T308/S473 与下游底物持续活化，输出“功能性 AKT 输出线索；上游来源未定位”。只有 pS6 或 pAKT 单一检测则输出不足以定位。若采样时使用 AKT 抑制剂，显示药物相关反馈混杂，不根据 pAKT 增高独立判耐药。
5. **上下游共同事件与治疗边界**：PIK3CA/AKT 与 MET/ERBB2/RTK、PTEN、RAS/MAPK 或组织学转化共存时，输出并行候选和对应确认步骤，不用没有校准的分数断言主要驱动。任何 PI3K/AKT 研究药物线索都必须携带癌种、治疗背景、研究类型、来源核验状态及“是否直接涵盖奥希替尼＋化疗后”的字段；未核验来源或间接人群不能标为临床推荐。

本文件不提供患者级药物剂量、个体组合方案、响应概率或医疗决定。判断器应保留“证据不足/无法判定”作为正常结果。
